# PPT Search v1.0.0

首个公开版本：在 Windows 上批量搜索本地 PPTX，显示文件名、实际幻灯片页码和命中文本，双击定位原页。

## 下载

- **PPTSearch-1.0.0-win64.zip**：Windows 10/11 64 位便携版。解压后双击 `PPTSearch/PPTSearch.exe`，保留整个文件夹，无须安装 Python。
- **PPTSearch-1.0.0-source.zip**：与 `v1.0.0` 标签一致的完整项目源码，含测试、构建脚本、依赖锁定文件和许可证。
- **SHA256SUMS.txt**：上述两个 ZIP 的 SHA-256 校验值。

## 功能

- 搜索标题、正文、表格、嵌套组合形状和讲者备注。
- 按实际排列顺序计页，隐藏页标记，稳定幻灯片 ID 用于原页跳转。
- 中文三栏界面、关键词高亮、按文件筛选、整页文字详情。
- SQLite 增量文本缓存、后台搜索、取消和新旧任务隔离。
- 复制命中文本和导出 Excel 可读取的中文 CSV。
- 全程本地离线处理，不上传课件，不下载模型。

## 验证

- 发布前自动化回归：11 项测试通过。
- 20 份、1,000 页固定样本与独立预期结果逐条比较一致。
- 本机此前已验证 PowerPoint 只读打开、第 7 页跳转、文稿复用和源文件未变化。
- 样本缓存搜索约 0.04 秒，原生 GUI 后续查询并展示约 0.39 秒，实际耗时依课件和机器而变。

## 使用要求与边界

- 精确跳转需 Microsoft PowerPoint；未安装时仍可搜索、导出并用默认应用打开文件。
- 读取已保存的 `.pptx`，不支持旧 `.ppt`、密码解密、图片 OCR、SmartArt/图表内部内容、嵌入附件或原页图片预览。
- `data` 缓存目录包含提取后的课件原文；分发或分享程序时请保留自己的数据目录在本地。
